## Conceitos A1

    -Estruturas onde cada posição de um array principal armazena uma referência para outro array 
    -Ao declarar int[][] array = new int[3][3]; você cria um array base de 3 posições, e cada uma dessas posições aponta para um novo 
     array de 3 posições
    -Ela funciona por meio de for aninhados, for I e for J
-

## Conceitos A2
    -Usando for-each
    -For-each faz o trabalho for comum, porem de forma mais facil
    -Ele cria uma variavel de referencia array e se move por ela
    -Logo em seguida vem outro for dentro que ira fazer uma referencia a ele

## Exemplos
    -Exemplo for-each
