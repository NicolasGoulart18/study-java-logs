## Conceitos

    -Estruturas onde cada posição de um array principal armazena uma referência para outro array 
    -Ao declarar int[][] array = new int[3][3]; você cria um array base de 3 posições, e cada uma dessas posições aponta para um novo array de 3 posições
    -Ela funciona por meio de for aninhados, for I e for J
